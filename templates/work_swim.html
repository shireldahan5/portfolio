(i)

What it does

Flexible bookings

Single, multi-session or recurring weekly lessons, for several children in one booking.

Live availability

I set and update open times from the admin side, so parents only choose from slots that are actually available.

Admin approval

An admin workflow where staff review and approve each request, and manage bookings and lesson sessions.

(ii)

How a booking moves

  1. Pick open times

    From the availability calendar.

  2. Send a request

    The parent gets an email saying it arrived, and I get notified.

  3. I review it

    Approve or decline in the admin page.

  4. Confirmed

    The parent gets a confirmation email with the details.

(iii)

Under the hood

I wrote the API routes and the SQLite data layer for bookings and availability, and a library of reusable, typed React components for the front end. A few of the files:

  • components/BookingForm.tsxThe five-step booking request
  • components/AvailabilityCalendar.tsxOpen times parents can choose from
  • app/api/bookingsAPI route that receives requests
  • app/api/availabilityAPI route for open times
  • lib/db.tsSQLite queries for bookings and availability
