About

I’m a second-year software engineering student at McGill. I got into web development by building things I needed, like the booking site for my swim lessons.

I like the part of software you can see: layout, type, spacing, and the small details that decide whether a page feels finished. Most of that I have learned with plain HTML and CSS, including freeCodeCamp’s Responsive Web Design certification.

Outside of class I’m on the electrical team at McGill Formula Electric. In the summer I teach swimming to children, which I have done since 2020.

I use Claude Code as a pair programmer and tutor, and I make sure I can explain every line I ship.
